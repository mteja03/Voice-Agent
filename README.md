# SB Ventures – Telugu Voice AI Sales Agent

Browser-based MVP that lets users speak in Telugu and converse with an AI real estate sales executive for SB Ventures.

## Pipeline

```
Browser mic → /api/conversation → Sarvam STT → GPT-4o → Sarvam TTS → Browser audio
```

## Prerequisites

- Node.js 18+
- [Sarvam AI API key](https://www.sarvam.ai) — for Telugu STT + TTS
- [OpenAI API key](https://platform.openai.com) — for GPT-4o

## Quick Start

### 1. Clone / open the project

```bash
cd "voice-agent"
```

### 2. Backend setup

```bash
cd backend
npm install
cp .env.example .env
# Add your keys to .env
npm run dev
# → Running on http://localhost:3001
```

### 3. Frontend setup (new terminal)

```bash
cd frontend
npm install
npm run dev
# → Running on http://localhost:5173
```

### 4. Open browser

Go to `http://localhost:5173`, allow microphone, tap the purple button and speak in Telugu.

## Environment Variables

```env
SARVAM_API_KEY=your_sarvam_api_key
OPENAI_API_KEY=your_openai_api_key
PORT=3001              # optional, default 3001
TTS_FIRST_CHUNK_MIN_CHARS=22   # lower = faster first audio, higher = fewer tiny chunks
TTS_NEXT_CHUNK_MIN_CHARS=52    # higher = fewer TTS calls after first chunk
TTS_CHUNK_MAX_CHARS=140        # force split long text even without punctuation
```

## API Reference

### `POST /api/conversation`

**Body:** `multipart/form-data`
| Field | Type | Description |
|-------|------|-------------|
| `audio` | File | WebM/Opus audio blob from MediaRecorder |
| `sessionId` | string | UUID generated by frontend for session continuity |

**Response:**
```json
{
  "transcript": "మీకు మంచి ప్లాట్ కావాలా?",
  "aiText": "అవును సార్, మాకు మంగళగిరిలో చాలా మంచి ప్లాట్లు ఉన్నాయి...",
  "audioBase64": "<base64 WAV string>"
}
```

### `POST /api/session/clear`

**Body:** `{ "sessionId": "uuid" }`  
Clears conversation history for that session.

## Known Limitations (MVP)

- Session memory is in-process only — restarts wipe all sessions
- No authentication or rate limiting
- iOS Safari may not support `audio/webm` — use Chrome or Firefox
